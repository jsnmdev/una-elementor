UNA-ELEMENTOR / FOUNDATION

Variables

These are the values we want available inside Elementor V4 before we build the reusable Global Classes. Elementor owns the production variables. This page is only the visual reference and calibration harness.

Elementor variable types: Color, Font, and Size. Shadows are intentionally excluded; shadow treatments become classes later. Typography role variables are limited to Display, H1–H6, and Body. Lead, Overline, Small, Caption, Meta, Helper Text, Legal Text, and similar roles belong to Global Classes.

BOUNDARY

What we deliberately do not turn into Variables

Shadows

Not Elementor Variables. Elementor only gives us Color, Font, and Size variables. Reusable shadows will be created later as Global Classes using Elementor settings.

Lead / Overline / Small / Caption / Meta / Helper / Legal / Text Link

These are semantic typography classes, not Type Scale variables.

Grid, Surface, Button, Media, Bleed

These are Global Classes built from Elementor native settings + the Variables above.
