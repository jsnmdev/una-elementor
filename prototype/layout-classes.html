UNA-Elementor Foundation / Layout Classes

Reusable structure before components.

This page validates only the reusable layout vocabulary. The production target is Elementor Global Classes built with Elementor layout settings, UNA Variables, and Elementor responsive controls.

Containers

container-full is the 1200px master content canvas with 20px safe side gutters. It stacks by default. container-read constrains sustained reading content.

Section Spacing

Section classes are numeric and map directly to the approved Fixed or Fluid spacing variables. No Compact / Default / Spacious presets.

section-48-fixed
section-96-fluid
section-140-fluid

Available V1 section classes: 40, 48, 56, 64, 80, 96, 120, then 140–300 in 20px increments; each has Fixed and Fluid variants.

Bleed Right

Bleed is structural and separate from grid proportion. The content remains anchored to the 1200px canvas while the selected child extends toward the viewport edge.

Content stays on-grid.

The bleed class belongs to the media/surface child, not to the whole page or an arbitrary widget offset.

bleed-right → viewport edge

Bleed Left

The left variant mirrors the same structural rule.

bleed-left → viewport edge

Same DOM responsibility.

At smaller breakpoints the bleed returns to the safe stacked composition rather than preserving desktop viewport-escape geometry.
