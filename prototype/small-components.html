Boundary Rule

Small Components V1 stops here.

Rating, Avatar, Promo, Counter, Icon Card, Badge, Stat, and Trust Mark cover the high-reuse primitives we need now. Divider is intentionally not duplicated because Elementor/Atomic already provides that primitive. New small components require evidence from real page assembly rather than speculative library growth.
