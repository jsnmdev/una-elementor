Ownership rules

Base button owns: touch target, padding, alignment, type treatment, radius, border baseline, focus compatibility, and restrained interaction.
Variant owns: Primary / Secondary / Outline / Text hierarchy.
Context owns: On Light / On Dark foreground, background, and border relationships.
Buttons do not own: section layout, CTA wording, container spacing, or business-action meaning.
