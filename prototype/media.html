Media ratio classes

Media classes own only the approved aspect ratio and cover behavior. Radius, layout, bleed, card framing, and section composition belong elsewhere.

Wide editorial and hero-support media.

media-1-1

Square cards, avatars, and balanced crops.

media-3-4

Portrait/provider composition.

Ownership rules

Media class owns: aspect ratio + object-fit cover.
Media class does not own: border radius, shadows, container width, bleed, alignment, or section spacing.
Elementor production: set ratio and cover through Elementor settings and save as Global Classes.
Local crop: object-position/focal point may remain a local media decision when the source image requires it.
