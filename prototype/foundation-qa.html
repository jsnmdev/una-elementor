Foundation approval checklist

01Variables

One source for color, fonts, type scale, spacing, widths, gutter, and radii.

02Base

Predictable native HTML defaults without component styling.

03Classes

Layout, surfaces, typography/content, buttons, and media remain composable and responsibility-bound.

04Forms

Gravity Forms is scoped and consumes UNA Variables without leaking globally.

05No band-aids

Repeated fixes promote into the system. True exceptions stay local overrides.

06Elementor ownership

Normal production behavior is Elementor Settings + Variables → Global Classes. CSS is reserved for unsupported/internal markup boundaries.
